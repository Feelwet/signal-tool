Hva kan gå galt

Høyt volum kan skyldes indeksendringer, emisjoner eller nyheter som allerede er priset. Stor bevegelse kan bety at nyheten allerede er priset (du er sen). Oppmerksomhet ≠ lønnsomhet; temaet kan snu ved nedtrapping. Meldepliktig handel kan være salg, opsjoner eller aksjelån – les meldingen. Risikopremien forsvinner raskt: olje- og tankaksjer kan gi tilbake ukers gevinst på dager. OPECs ledige kapasitet og strategiske lagre demper topper; markedet kan allerede prise en stor premie.
